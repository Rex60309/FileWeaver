# Windows local benchmark — 2026-11-13

These measurements use the current Release CLI and generated data on one PC.
All query results and index snapshots were checked. The raw reports stay under
`build/benchmarks/final-20261113/`; the accompanying JSON records their hashes.

## Machine and setup

- CPU: 13th Gen Intel(R) Core(TM) i7-13700KF; RAM: 34104291328 bytes.
- OS: Windows-11-10.0.26300-SP0; GNU 13.2.0 Release, C++20.
- Storage: NVMe KINGSTON SKC3000S1024G SSD, verified from the C: partition/disk mapping.
- Product source: `ca314e533239d1155dd025d45e4c418a913e9b2a`. CLI SHA-256: `00f355ccf5ec4d36cc548e67f1484bbb6f25daa2526e7db591d09e1bffa6c900`.

## Indexing and rescans

Seconds, three rounds per size. Each round initializes a fresh catalog before
timing. The separate index fixture starts with unique zero-byte Unicode filenames in 27 subdirectories;
changes accumulate between rounds. The changed scan follows 10 creations,
10 size/mtime updates, 10 renames and 10 deletions. It rescans all files.
Snapshot/counter validation runs outside the timer. Database sizes include
any remaining WAL/SHM files and depend partly on absolute path lengths.

profiling next; these measurements do not identify the cause.

## Reproduce

Build the Release CLI, set TEMP/TMP to a writable temporary directory, then run
the following for each size (10000 and 100000). Use new output paths on rerun.

```powershell
$files = 100000
python benchmarks/search/benchmark_search.py --cli build/release/fileweaver.exe --core-runner build/release/search_core_benchmark.exe --cli-memory --build-info build/release/benchmark-build-info-Release.json --files $files --dataset nested-unicode --repetitions 30 --warmups 3 --storage-kind ssd --storage-model "NVMe KINGSTON SKC3000S1024G" --output build/benchmarks/search-local.json
python benchmarks/search/fuzzy_search.py --cli build/release/fileweaver.exe --build-info build/release/benchmark-build-info-Release.json --rows $files --repetitions 30 --storage-label "NVMe KINGSTON SKC3000S1024G; SSD" --output build/benchmarks/fuzzy-local.json
python benchmarks/search/index_updates.py --cli build/release/fileweaver.exe --build-info build/release/benchmark-build-info-Release.json --files $files --rounds 3 --storage-label "NVMe KINGSTON SKC3000S1024G; SSD" --output build/benchmarks/index-local.json
```

Use your own storage label. The scripts create temporary fixtures automatically
and do not scan your existing folders. Choose a fresh output filename for every
run; the fuzzy driver will replace an existing report.

## Project checks

Core Debug/Release CTest: 13/13 each; desktop Debug/Release: 16/16 each.
Core/desktop format and lint passed. A Git archive without local planning files
configured and compiled core, storage, desktop UI and preview-renderer libraries
using the existing pinned dependencies. This is not a fresh dependency install
or installer test. Windows GUI combined ASan/UBSan is unsupported locally;
no new hosted MSVC/sanitizer run was started because Actions remains paused.

The index timer passed a two-round 100-file correctness smoke and rejects
invalid limits and existing output files. No product source files or user
data were changed by the measurements. GUI latency, previews, larger datasets
and controlled cold-cache behavior are still unmeasured.
